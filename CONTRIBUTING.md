# Contributing

IWU-S20 is intended to be challenged and improved in public. Open an issue before
large changes so the measurement claim, estimand, and falsification plan can be
discussed before implementation.

Changes to the formula or normative record require:

1. a written failure mode or use case;
2. a predeclared falsification test;
3. Python and JavaScript conformance fixtures;
4. explicit compatibility and migration notes; and
5. updated claim boundaries.

Bug fixes should include a regression test. Empirical claims should include the
data boundary, reference, verifier, sampling unit, dependence assumptions, and
enough evidence for reproduction.
